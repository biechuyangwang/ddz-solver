## Interaction Contracts

### Tab System

| Interaction | Behavior |
|-------------|----------|
| Click tab | Switches active view; overview tab shows ResultHeader content; tree tab shows DecisionTreeView; simulation tab shows SimulationView |
| Keyboard left/right arrow | Navigate between tabs (focus management) |
| Tab underline | 2px solid blue-600 under active tab; transparent under inactive |
| All three tabs visible at all times | No tab hiding based on state; disabled state for tree/sim if not winnable |

### Decision Tree View

| Interaction | Behavior |
|-------------|----------|
| Click node | Selects node; opens/shows detail panel on right; highlights selected node with ring (ring-2 ring-blue-400) |
| Click expanded node with children | Collapses children (sets hidden: true on descendant React Flow nodes/edges) |
| Click collapsed node | Expands immediate children; re-runs dagre on visible nodes only |
| Pan/zoom | React Flow built-in mouse wheel zoom + drag pan; touch pinch-zoom on mobile |
| Click empty canvas | Deselects node; hides detail panel |
| Initial render | Root node expanded to depth 2; deeper nodes collapsed |

### Tree Node Detail Panel (Right Sidebar)

| Interaction | Behavior |
|-------------|----------|
| Panel open | Slides in from right; tree area remains full-width underneath (panel overlays or pushes content) |
| Panel close | X button or click empty canvas; slides out to right |
| Panel content | Shows: move played, player label, player remaining hand (cards), opponent remaining hand (cards) |

### Simulation View

| Interaction | Behavior |
|-------------|----------|
| Next button | Advance one step; animate slide-left transition |
| Prev button | Go back one step; animate slide-right transition |
| Auto-play button | Starts interval at current speed; button text changes to "暂停"; icon changes from Play to Pause |
| Speed selector | Three options (0.5x = 3000ms, 1x = 1500ms, 2x = 750ms); active speed highlighted with blue underline |
| Step slider/jump | Slider or clickable progress bar to jump to any step |
| Opponent response click | Re-routes simulation through that opponent branch; resets steps from that point forward |
| Step transition | framer-motion AnimatePresence with directional slide (200px, spring stiffness 300, damping 30) |

### Opponent Responses Display

| Interaction | Behavior |
|-------------|----------|
| Display | List of text labels (e.g., "Pair-3", "Single-5", "过") |
| Winning response | Highlighted with green text (text-green-600 font-semibold) |
| Non-winning response | Default gray text (text-gray-500) |
| Click any response | Re-routes simulation; all children of that response become the new path |

## Empty and Edge States

| State | Condition | Display |
|-------|-----------|---------|
| Not solved | status !== 'done' | Tab content shows empty state message per tab |
| Solved but lost | result.winnable === false | Overview shows "无必胜策略" (existing); Tree and Simulation tabs disabled (grayed, tooltip "仅支持必胜局面") |
| Solved, won, but no tree | result.tree === null | Should not happen for winnable positions; fallback error message |
| Tree tab, very large tree (>500 nodes) | node count > 500 | Start with depth-1 expanded only; warn user in console |
| Simulation, single step | optimal path has 1 step | Controls show step 1/1; next button disabled |
| Selected node is root | pathIndex === '0' | Detail panel shows initial hands, no "出牌" section |
