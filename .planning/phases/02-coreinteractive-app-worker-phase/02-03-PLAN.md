Create three components implementing the complete solve flow and result display.

**1. src/components/ElapsedTime.tsx** -- Live elapsed time counter:
   - Reads `solveStartTime` from store
   - Uses `useState` + `setInterval` (100ms update) to show elapsed seconds
   - Displays "已用时 {X}s" format (per UI-SPEC Copywriting Contract, Approach B)
   - Only renders when `status === 'solving'` and `solveStartTime !== null`
   - Clears interval on unmount (useEffect cleanup)
   - Styling: `text-sm text-gray-500`
   - Format: show 1 decimal place, e.g. "已用时 3.2s"

**2. src/components/SolveButton.tsx** -- Solve trigger with progress and cancel:
   - Props: `{ canSolve: boolean }` (true when both hands have cards)
   - Reads from store: `status`, `startSolving`, `cancelSolving`
   - Three visual states:
     a. **idle + canSolve**: Blue button "开始求解" -- `bg-blue-600 hover:bg-blue-700 text-white w-full py-3 rounded-lg font-semibold text-xl`
     b. **idle + !canSolve**: Gray disabled button "开始求解" -- `bg-gray-300 text-gray-500 cursor-not-allowed w-full py-3 rounded-lg font-semibold text-xl`, with `disabled` attribute
     c. **solving**: Shows two elements side by side (`flex gap-2`):
        - Disabled button "求解中..." with CSS spinner (animated rotating border)
          - Spinner: 20px square, `border-2 border-gray-300 border-t-blue-600 rounded-full animate-spin` (Tailwind built-in)
        - Red cancel button "取消求解" -- `bg-red-600 hover:bg-red-700 text-white px-4 py-3 rounded-lg font-semibold`
        - Below both: ElapsedTime component
     d. **done/error**: Same as idle+canSolve (shows "开始求解" to re-solve)
   - Add `aria-busy={status === 'solving'}` to the solve button
   - Add `aria-live="polite"` to the container for result announcements

**3. src/components/ResultPanel.tsx** -- Win/lose result + statistics:
   - Reads from store: `status`, `result`, `errorMessage`
   - Only renders when `status === 'done'` or `status === 'error'`
   - Layout: white panel `bg-white rounded-lg p-6 shadow-sm`
   - **Win state** (result.winnable === true):
     - Large green badge: "必胜" in `text-3xl font-semibold text-white bg-green-600 px-6 py-2 rounded-lg inline-block`
     - Best move section: label "最佳出牌" in `text-sm font-semibold text-gray-500`, followed by the move's cards displayed as card values
       - Display bestMove.cards as Chinese card names: map each card value through VALUE_DISPLAY, joined by spaces
       - Example output: "3 4 5 6 7" for a straight, or "小王 大王" for a rocket
     - Per UI-SPEC: "必胜" badge uses `#16a34a` (green-600) background
   - **Lose state** (result.winnable === false):
     - Text: "无必胜策略" in `text-xl font-semibold text-red-600` (per UI-SPEC: destructive color #dc2626)
   - **Statistics table** (shown for both win and lose, when result exists):
     - Three rows in a simple grid layout (`grid grid-cols-[auto_1fr] gap-x-4 gap-y-1`):
       - "搜索节点数" : result.stats.nodesExplored.toLocaleString()
       - "用时" : formatted time. If timeMs < 1000 show "{X}ms", else show "{X.X}s"
       - "置换表命中" : result.stats.transpositionHits.toLocaleString()
     - Label in `text-sm font-semibold text-gray-500`, value in `text-sm text-gray-700`
   - **Error state** (status === 'error'):
     - Error icon + message in `text-red-600 font-semibold`
     - For timeout: show "求解超时，请尝试更少的手牌或增加时间预算"
     - For other errors: show errorMessage from store
