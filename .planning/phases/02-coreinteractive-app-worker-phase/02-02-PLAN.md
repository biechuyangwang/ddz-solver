**1. src/components/CardPicker.tsx** -- Full 54-card deck grid:

   - Props: `{ activeTarget: PlayerTarget }`
   - Reads from store: `playerCards`, `opponentCards`, `addCard`, `status`
   - Compute `usedCounts` array (length 15) by counting occurrences of each card value across BOTH playerCards and opponentCards combined
   - Layout: CSS grid
     - 4 rows for regular cards: `grid-cols-13` (use inline style `gridTemplateColumns: 'repeat(13, 1fr)'` since Tailwind has no built-in grid-cols-13)
     - Each cell: a CardFace for the suit+value combination
     - 1 row below for jokers: 2 CardFace items centered
     - Grid gap: `gap-1` (4px)
   - For each regular card (4 suits x 13 values):
     - value = column index + 1 (A=1, 2=2, ..., K=13)
     - suit = row suit (spade, heart, club, diamond)
     - Determine state:
       - If `usedCounts[value - 1] >= maxCountForValue(value)` => state = 'disabled'
       - Else state = 'default'
     - onClick: call `addCard(activeTarget, value)`
   - For jokers (14=小王, 15=大王):
     - state based on `usedCounts[jokerValue - 1] >= 1` (max 1 each)
     - onClick: call `addCard(activeTarget, jokerValue)`
     - No suit for jokers
   - The entire picker grid wrapped in a white panel: `bg-white rounded-lg p-4 shadow-sm`
   - Instruction text above grid: "点击选择手牌" in `text-sm text-gray-500 mb-2`
   - Disable all clicks when `status === 'solving'`
